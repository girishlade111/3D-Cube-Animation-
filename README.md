# 3D Cube Animation 💫

Two interactive CSS-only 3D cube animation demos rendered with pure CSS 3D transforms — no libraries, no build step. Open either file in a browser and watch a glowing cube rotate in 3D space.

## Demos

| File | What it shows |
|------|---------------|
| `3D Cube Animation 💫.html` | Interactive 3D cube with CSS 3D transforms, perspective camera, adjustable rotation speed |
| `3D ब्यूटीफुल Cube ◻️ .html` | Stylish glowing 3D cube with gradient background and neon accents |

## Features

- Pure CSS 3D transforms (`transform-style: preserve-3d`, `perspective`, `rotateX/Y/Z`)
- Smooth continuous rotation animations (`@keyframes`)
- Glowing/neon face styling with gradients and shadows
- Fully responsive — cube scales to viewport
- Zero dependencies, single self-contained HTML files

## Quick start

No build, no install. Just open a demo file in any modern browser:

```bash
git clone https://github.com/girishlade111/3D-Cube-Animation-.git
cd 3D-Cube-Animation-
# then open "3D Cube Animation 💫.html" in your browser
```

Or view the live demo on GitHub Pages.
